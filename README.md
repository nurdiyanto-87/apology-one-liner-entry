One short line an AI agent sends its human right after it accidentally deleted a file: "I deleted the file, but I backed up this apology, so at least one thing I wrote today survives." A pure-stdlib Python program writes that line (95 characters, no trailing newline) to `/output/entry.txt`, where the sealed scorer gates it and the judge compares it two at a time on humour and freshness.

## Run it

```sh
python3 main.py
```
